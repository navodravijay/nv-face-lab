## Security & Privacy

NV. FACE LAB is designed with privacy-conscious principles.

- Camera access requires user permission.
- Camera frames are processed locally in the browser.
- No built-in facial identity database.
- The application does not intentionally record or upload camera frames.
- External MediaPipe code and models are downloaded from third-party servers. MediaPipe may transmit usage and performance metrics.
- Browser security headers and permissions restrictions are configured.

Security protections do not constitute a guarantee against all vulnerabilities.
